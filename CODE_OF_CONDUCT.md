# Code of Conduct

queuetruth follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project's spaces: issues, pull requests, discussions and any other channel
the project uses, and to people representing the project elsewhere.

In short: be respectful and constructive, assume good faith, and keep criticism about code, data and results rather
than about people. Harassment, personal attacks and discriminatory language are not acceptable.

## Reporting

Report unacceptable behaviour privately to the project maintainer through the contact listed on the maintainer's
GitHub profile, or, for anything that also involves a security problem, through the private process in
[SECURITY.md](SECURITY.md). Reports are handled confidentially. The maintainer will review each report and decide on
the response, following the enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary
ban or permanent ban).

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
